# 개인 기여 범위

## 직접 담당

- Kubernetes 애플리케이션 배포/인프라 구성
- MetalLB 및 외부 VIP 구성
- NGINX Ingress Controller 구축
- HTTPS/Ingress 외부 접근 구성 및 검증
- Ingress Controller 이중화 구성 및 검증
- Ingress Pod 1개 장애 테스트
- Worker Node 장애 테스트
- 장애 상황에서 서비스 지속 및 VIP 이동 확인
- Ansible을 이용한 일부 Kubernetes 구축/배포 자동화 과정 참여

## 팀 공용 또는 담당 외 영역

- 전체 애플리케이션 개발
- CI/CD 파이프라인 구현
- `ansible/team-reference/`의 클러스터 구축 자동화 자료는 팀 프로젝트 공용 자료로 분리

이 구분은 팀 프로젝트의 전체 결과와 개인 기여를 혼동하지 않기 위해 명시했습니다.
